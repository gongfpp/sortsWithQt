# sortsWithQt

> 基于 Qt Widgets 的排序算法练习：生成一组整数，单项排序可查看排序结果与耗时；“全过一遍”依次运行五种实现以比较耗时。

## 工作流程示意

```mermaid
flowchart LR
    A[生成 50,000 个随机整数] --> B{选择操作}
    B --> C[单项排序]
    B --> D[全过一遍]
    C --> E[显示排序结果与耗时]
    D --> F[记录五种算法的耗时]
```

> 这是依据源码绘制的流程图，不是程序界面截图；仓库目前没有 UI 截图资源。

## 功能

- 生成默认数量为 50,000 的随机整数，并显示未排序列表。
- 单独运行冒泡（按钮名称）、快速、希尔、堆或基数排序。
- 点击 **全过一遍**，在同一组输入数据的五个副本上依次运行五种实现并记录耗时；该操作不会把排序结果显示到结果框。
- 单项排序会显示结果和毫秒计时；耗时仅供本机练习参考，不是跨机器性能基准。

## 构建与运行

### 环境要求

- Qt Creator 与包含 **Qt Widgets** 的 Desktop Kit。
- 与所选 Qt Kit 匹配的 qmake 和 C++11 编译器（MinGW 或 MSVC）。

### 使用 Qt Creator

1. 打开 `Sort.pro`。
2. 选择并配置已安装的 Desktop Kit。
3. 构建项目并运行。

### 使用 MinGW 命令行

在已配置 Qt/MinGW 的命令行中，从仓库根目录执行：

```bat
mkdir build
cd build
qmake ..\Sort.pro
mingw32-make
```

使用 MSVC Kit 时，在对应的 Qt/MSVC 开发者命令行中运行 qmake，并以 `nmake` 替换 `mingw32-make`。

## 实现与限制

- 核心实现位于 `mainwindow.cpp`；输入使用 `QVector<int>`，界面通过 Qt Widgets 显示输入、输出与计时。
- UI 标为“冒泡排序”的函数并非传统相邻交换式冒泡排序，而是逐项与后续元素比较并交换。
- 基数排序当前循环只进行 `d - 1` 轮（`d` 为最大值位数），可能漏掉最高位，不能假定结果始终有序。
- 生成数量固定为 50,000；随机数由 `rand()` 产生。计时结果受本机环境影响，生成耗时还包含逐项更新文本框的开销。
- 仓库没有自动化测试目标或预编译发布包。
